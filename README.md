## 프로젝트 목표

이 프로젝트는 VirtualBox (또는 VirtualBox를 사용할 수 없는 경우 UTM)를 사용하여 가상 머신을 만드는 것입니다. </br>
구체적인 목표는 아래의 특정 규칙을 준수하면서 가상 머신의 운영 체제를 설정하는 것입니다.

## 일반 지침

* VirtualBox (또는 UTM)는 이 프로젝트에 필수적입니다.
* 제출물은 가상 디스크의 서명이 담긴 `signature.txt` 파일 하나로 구성됩니다.

## 필수 파트

필수 파트는 특정 설정을 통해 서버를 설정하는 것을 포함합니다:

* 최신 안정 버전의 Debian 또는 Rocky Linux 설치 (Debian이 초보자에게 권장되며, 저는 Debian을 사용했습니다).
* 그래픽 인터페이스 없음 (X.org 또는 동급 금지).
* LVM을 사용하여 최소 2개의 암호화된 파티션 설정.
* SSH 서비스는 포트 4242에서 실행 (root로 SSH를 통한 로그인은 비활성화).
* UFW를 구성하여 포트 4242만 허용.
* 호스트 이름 설정 (yourlogin42).
* 강력한 비밀번호 정책 구현.
* Sudo 구성 (잘못된 비밀번호 시도 제한, 사용자 정의 오류 메시지, 로깅, TTY 모드 활성화, 제한된 경로).
* 10분마다 서버 정보를 표시하는 bash 스크립트 (`monitoring.sh`).

## 보너스 파트

보너스 파트에는 추가 작업이 포함됩니다:

* 특정 구조와 일치하도록 파티션 설정.
* lighttpd, MariaDB 및 PHP를 사용하여 WordPress 웹사이트 설정.
* 추가 서비스 설정 (NGINX/Apache2 제외).

## 참고 사항

* 가상 디스크 서명이 포함된 `signature.txt` 파일만 업로드되었습니다.
* 실제 평가에서 가상 머신을 제출하는 것은 금지되어 있습니다.
* 서명은 가상 디스크 파일 (.vdi 또는 .qcow2)에서 가져올 수 있으며, 평가 중에 가상 머신의 서명과 비교해야 합니다.
